## Findings

### 1. docs/security/NPM-PROVENANCE.md:60 — a release artefact described before any release has produced one

- Claim: *"From 0.2.34 the publish workflow attaches three files to the GitHub
  release"*, followed by a table of the tarball, the CycloneDX bill of materials
  and the build attestation.
- Mechanism: the steps added to `.github/workflows/publish.yml` in #28 — fetch
  the published tarball, check its sha512 against the registry's
  `dist.integrity`, run `npm sbom`, attest, and create the release with all
  three attached.
- Why it falls short: those steps have never executed. The workflow is
  dispatch-only and 0.2.34 is the first release that would run them, so at the
  moment the sentence was written it described an intention, not an artefact.
  This is the same shape as the defect 0.2.33 was published to fix — that page
  said *"This is not a published release"* eight releases in — with the sign
  reversed: asserting an artefact exists before it does rather than after it
  stopped being true.
- Disposition: reworded in `d816ce1`. The section now says the workflow is
  *configured* to attach them, that the steps have not run yet, and that the
  release page is the answer to whether a given version has them. The `gh
  attestation verify` block carries the same condition and says every version
  published so far has only npm's attestation.

### 2. docs/PRIOR-ART.md — checked and not a finding, recorded because it is the reason for the release

- Claim: the Vaara row scores that project **Yes** on coverage reconciliation,
  and the file now warns above its own table that part 3 is no longer ours
  alone.
- Mechanism: `docs/design/credential-broker-spec.md` §D in `vaaraio/vaara` at
  `befdced`, read directly: each used credential is joined to a receipt on
  `attestationDigest`, and a used credential with no matching receipt — or a
  provider action with no credential — is read as a bypassed broker.
- Why it does not fall short: this is a correction against our own interest, and
  the narrower sentence that replaces it names what still holds (masking before
  disclosure, then reconciliation) rather than restating the old one in softer
  words. The enforcement column stays **Partial** on measured grounds: the
  gateway authorizes calls, and a grep for value masking found only GDPR Art. 17
  erasure inside the audit store, which is a different guarantee. "No value
  masking **found**" is written as a limit of the search, not as an absence
  proven.
- Disposition: accepted as written.
