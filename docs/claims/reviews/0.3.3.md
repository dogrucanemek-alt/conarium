## Findings

### 1. docs/API-STABILITY.md:33 — "There is no `exports` map."

- Claim: "There is no `exports` map." and, in the Package exports table, "`exports` field | **absent**"
- Mechanism: `package.json` without an `exports` field
- Why it falls short: #147 added the map, so both statements were false on
  `main` from 0513cfd. The claims gate did not notice: it reads a document
  only when the document changes.
- Disposition: reworded in `0fefb60`, with `test/api_stability_exports.mjs`
  comparing the table to `package.json` from now on

### 2. docs/API-STABILITY.md:168 — "passes every deep path through as before the map existed"

- Claim: "passes every deep path through as before the map existed"
- Mechanism: resolving deep paths by name under the new map
- Why it falls short: `@conarium-ai/core/dist/governance.js` resolves, but the
  extensionless `@conarium-ai/core/dist/governance`, which `require` resolved
  before the map existed, now fails with `MODULE_NOT_FOUND`
- Disposition: reworded in `3caffbe`; the changelog names the change

### 3. CHANGELOG.md (0.3.3, first draft) — "a count per class"

- Claim: "`maskField` returns the masked text, the number of masked regions and a count per class."
- Mechanism: `maskField`'s `byClass` for a text with an e-mail address and a TCKN
- Why it falls short: `byClass` came back `{}`; it counts custom patterns only, and the built-in
  classes had no count at all. The changelog is not a claim surface, so the gate did not read it.
- Disposition: the sentence was replaced in `47e0832` after `cdbd65e` added `classes` and
  `masked`, which `src/mask-classes.test.ts` checks
