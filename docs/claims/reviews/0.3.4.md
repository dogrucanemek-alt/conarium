## Findings

### 1. docs/API-STABILITY.md:169 — "spoken and dotted addresses without `@`"

- Claim: "spoken and dotted addresses without `@`"
- Mechanism: `findDottedEmails` in `src/mask/speech.ts` keeps a run of four
  or more dotted labels only when the first two labels are letters only
  and the last is a known TLD
- Why it falls short: `ayse2.yilmaz.example.com` is four dotted labels
  without `@` and is not masked — the first label is not letters only
- Disposition: reworded in `1072dac` to "four or more dotted labels whose
  first two are letters only"

### 2. CHANGELOG.md (0.3.4, first draft) — "four or more dotted labels without `@`"

- Claim: "addresses said with `et` / `at` and `nokta` or written as four
  or more dotted labels without `@`"
- Mechanism: the same `findDottedEmails` rule as finding 1
- Why it falls short: the changelog is not a claim surface, so the gate
  did not read it; the sentence still claimed every four-label dotted run,
  including `ayse2.yilmaz.example.com`
- Disposition: reworded in `1072dac`

### 3. CHANGELOG.md (0.3.4, first draft) — "It leaves amounts"

- Claim: "It leaves amounts, times, dates, two years joined by one space
  or one hyphen"
- Mechanism: a run of 7 or more digits split by spaces or hyphens is
  masked (`findDigitRuns`); `1.250.000` and `14:30` are not such a run
- Why it falls short: `1 250 000` is the same digits written with spaces
  and is a run, so it is masked. What stays is an amount written with
  dots or commas and a time with a colon
- Disposition: reworded in `1072dac`
