## Findings

### 1. docs/API-STABILITY.md:169 — spoken and dotted addresses without a named ending list

- Claim: "spoken `et` / `at` and `nokta` addresses and four or more dotted
  labels whose first two are letters only"
- Mechanism: `findSpokenEmails` and `findDottedEmails` in `src/mask/speech.ts`
  keep a run only when the last label is in `DOMAIN_ENDINGS`
- Why it falls short: `ayse.yilmaz.example.xyzzy` is four dotted labels
  whose first two are letters only and is not masked — `xyzzy` is not in
  the list
- Disposition: reworded in `bf49021` to name `DOMAIN_ENDINGS` in
  `src/mask/speech.ts` and that an address ending in anything else is not
  masked by these rules

### 2. CHANGELOG.md (0.3.4, previous wording) — "an amount written with dots or commas"

- Claim: "It leaves an amount written with dots or commas"
- Mechanism: `findDigitRuns` masks a run of 7 or more digits; thousands
  separators (`1.250.000`, `1.250,00`) break the run, and fewer than 7
  digits before a decimal comma stay
- Why it falls short: `1234567,89` is written with a comma and is a run
  of 7 digits, so it is masked
- Disposition: reworded in `bf49021`
