## Findings

### 1. docs/RECEIPT-SPEC.md:616 — what the bound is compared with

- Claim: "how many source statements one receipt may cover"
- Mechanism: `d.delta <= max` in `projectResultV2`
- Why it falls short: the comparison is one pattern's statement count in the
  window. The number of receipts does not enter it, so the sentence described a
  rule the implementation does not apply. This predates the release and was
  found while checking the boundary change.
- Disposition: the row now states the comparison, `LIMITATIONS.md` states the
  consequence, and tests hold both. The behaviour is not changed here, because
  changing it moves `matched` outcomes and needs a decision on what the bound
  counts.

### 2. README.md:6 — the Agora badge

- Claim: alt text "Agora: MCP handshake check", and the image, which read
  "agora" and "runs locally" when this review was written
- Mechanism: a third-party site's own check, served as a remote image
- Why it falls short: this repository does not establish what that check tests,
  and the image can change without a release of this package
- Disposition: kept. The badge is attributed to its publisher and links to its
  listing, and it makes no statement in this project's voice.
