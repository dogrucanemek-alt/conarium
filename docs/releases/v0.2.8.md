# Draft — Conarium 0.2.8

**Taslak.** GitHub Release yayımlanmadı. Tag `v0.2.8` = `ea563b9`.

Console grows a desktop launcher and a receipts tab. The public demo stops
breaking MCP clients that probe `/.well-known/*`.

## Added

- `conarium-console --install-shortcut` / `--uninstall-shortcut`. Opens the
  existing loopback console after the port listens. Browser gets a one-time
  `/handoff` nonce (≤30s). The long-lived token is not put in the URL.
- Console **Makbuzlar** tab: lists `audit.receiptSink` newest-first, opens the
  same receipt HTML as `/proof`, shows zincir sağlam / kırık. Renderer is
  `src/receipt-view.ts`.

## Fixed

- HTTP gateway returns 404 (plain text) for `/.well-known/*`. A 302+HTML
  catch-all made some MCP clients treat the redirect body as authorization
  metadata. Caddy must still 404 these paths first.

Not a dialect release. SQL remains Postgres only.
