# Draft — Conarium 0.2.9

**Taslak.** GitHub Release yayımlanmadı. Tag `v0.2.9` = `73f7a86`.

Operator-facing console and proof page, plus a config-time custom PII
pattern. A design note for Oracle/MSSQL exists; there is no dialect code.

## Added

- Custom PII pattern from config. ReDoS-shaped input is rejected at compile.
- Desktop / panel mark from the existing SVG (`.ico` / `.icns` / 512 PNG).
- `c1` sets `CONARIUM_AUDIT_SIGNING_KEY` from `~/.conarium/audit-ed25519.pem`
  when `receiptSink` is set. The sink file is not invented empty.

## Fixed

- `/proof` HTML shows known English sentences in Turkish. JSON bytes unchanged.
- Makbuzlar tab paints "Yükleniyor…" on the click that switches the tab.
- Receipt download returns bytes; file name is sanitised.

## Docs

- `docs/specs/2026-08-14-oracle-mssql-dialect-design.md` — design only.
  Oracle, MSSQL, and MySQL are not implemented.

Not a dialect release. SQL remains Postgres only.
