# Building the preprint PDF

This machine has no `pandoc`, no `xelatex`, and no `tectonic` (`where.exe` was empty on 22 August 2026). The PDF was **not compiled** here. Do not read `paper/arxiv/main.tex` as a file that has been shown to build.

`paper/arxiv/main.tex` was written by hand from `paper/two-ledgers-one-window.md`. It was not generated by pandoc.

## Correspondence (source vs tex)

Measured on the tree that carries this file:

- Markdown `##` headings map to LaTeX `\section`.
- Markdown `###` headings map to LaTeX `\subsection`.

Run, from the repository root:

```
# PowerShell
(Select-String -Path paper/two-ledgers-one-window.md -Pattern '^## ' -AllMatches).Count
(Select-String -Path paper/arxiv/main.tex -Pattern '\\section' -AllMatches).Count
(Select-String -Path paper/two-ledgers-one-window.md -Pattern '^### ' -AllMatches).Count
(Select-String -Path paper/arxiv/main.tex -Pattern '\\subsection' -AllMatches).Count
```

Those four numbers must pair: 11 sections with 11 sections, 3 subsections with 3 subsections. If they do not, the tex has drifted and is not a build of the markdown.

## Path (a) — arXiv compiles it

Upload `paper/arxiv/main.tex` and `paper/arxiv/refs.bib` as the source. arXiv's own compiler produces the PDF. Category suggestion (decision is not made here): primary `cs.CR`, secondary `cs.DB`.

`main.tex` starts with `\pdfoutput=1` for that pipeline.

## Path (b) — Overleaf

Upload the `paper/arxiv/` directory. Compile with pdfLaTeX. Do not install a TeX distribution on this machine to force a local PDF.

## Generated PDF

If a PDF is produced later, write it under `paper/build/` and nowhere else. That directory is gitignored. A generated PDF committed under `docs/` would enter the npm allow-list; `test/pack_tracked.mjs` is right to refuse a package built from files the repository does not describe.
